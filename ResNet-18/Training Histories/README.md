# Recorded training and validation

The five condition folders contain the completed three-seed runs. `run_summary.csv` lists the selected best epoch, last completed epoch and validation macro-EER.
`history.jsonl` and `curves.png` are exact copies of the original records. `configuration.json` retains the scientific settings with portable asset binding, rather than author-machine paths.
No test result selects an epoch. Public model metadata and expected checkpoint locations are in [the checkpoint index](../../Assets/checkpoints.json).
